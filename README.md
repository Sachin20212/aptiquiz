# AptiQuiz — 1000 Unique Worldwide Questions

Features:
- 1,000 unique worldwide questions
- 15-second timer per question
- Correct answer = 100 points
- Wrong answer = 0 points
- Skip button advances immediately and awards 0 points
- Timeout awards 0 points
- Everyone starts at 0
- Questions do not repeat until the full bank has been used
- Each question contains topic, question text, four options, answer index, and correctAnswer

- Responsive quiz interface optimized for laptop and mobile displays
- Timer warning state at 5 seconds and critical state at 3 seconds
